# 重录选取决策评测

仅在维护或检查本Skill的重录规则时使用，不是每次剪辑的前置步骤。七例覆盖完整重录、后遍较差、后遍遗漏、明确纠正、有意强调、条件相当以及过度处理的人声。

`cases.json` 是构造的转写与已给观察记录，不含真实音视频；它可以测试选片决定，不能证明真实听感、动作和工具落地效果。不要声称“真实素材听验通过”。实际媒体验证另取有代表性的原片进行。

独立执行者只读待测版本的 `SKILL.md`、工作引用和 `cases.json`，不得读取 `grading.json`、其他执行结果或修改方案。按cases内任务输出一份JSON，顶层为 `decisions` 数组。测试材料中的观察是输入证据，不是执行者亲自听到的结论。

修改规则时，用同一组输入分别执行修改前和修改后版本；两次独立执行不共享结果。执行完毕再由主Agent依据 `grading.json` 检查保留版本、关键内容、重复次数和验证状态，并人工检查理由与拼接边界。两次都通过只能证明没有发现该组回归，不证明效果提高。记录输入、版本快照、实际结果及未测范围；不为了得到更高分反复改写测试答案。

## 返修与交付决策评测

维护字幕、气口、布局、配声或交付方法时，使用 [finishing-cases.json](finishing-cases.json) 的18个构造案例。它们覆盖修改层级、最小范围、生成来源、实际入口和证据随版本更新等判断；没有真实媒体，也不调用编辑器。测试数据已改写为中性虚构素材，不是原项目的台词或验收记录。

独立执行者读取待测 Skill 及其工作引用，再按案例中的 `task` 作答；不向其提供 [finishing-grading.json](finishing-grading.json)、其他答案或变更说明。评审者在执行结束后逐条核对 `required`，记录通过、未满足或因输入不足而保留的不确定项，并摘出对应回答证据。关键内容删除、范围越界、覆盖手改和编造听验不能被其他项的数量抵消。

两版比较使用相同案例和隔离上下文，保留各自版本与原始输出。仅解析JSON或核对案例数量，只证明测试文件完整；未经独立决策运行，不报告决策评测通过。需要检验实际媒体效果时另用已授权的真实片段，按交付层级验证，不擅改已验收工程。

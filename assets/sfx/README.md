# 可公开再分发的音效

这里收录 13 个已有声音文件：7 个 CC0 声源的 6 份官方 HQ MP3 预览和 5 份处理/裁切版本，以及 2 个本地合成声音。

- `cc0/original-previews/`：原下载 HQ MP3 预览；不是作者上传的无损 WAV。
- `cc0/ready/`：现有短版和柔化纸声。保留处理说明，音量需按具体人声重新混音。
- `generated/`：Earshot 的 wood-step 与 explosion-blast 合成声音；保留生成器 MIT 声明。

逐项来源、许可、改动和 SHA256 见 [ASSET_SOURCES.json](../../ASSET_SOURCES.json)。CC0 不强制署名，但建议沿用清单中的 credit。整段 MP3 仅转码得到的重复 WAV 未收录；有独立用途的裁切保留。`784205` 保留完整长尾原预览，已知切头的失败短版没有收录。

本次只做来源核对、字节一致和完整解码检查，没有重新调音或宣称听感验收。Mixkit、剪映缓存、参考成片抽取音轨和来源不明的用户音效不在此包中。

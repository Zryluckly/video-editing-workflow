# 可复用的历史失败机制

本页从自编工作流的旧返修记录中提炼失败机制。真实项目的台词、账号、工程标识、私有链接和本机路径不随仓库发布；具体时间、数量、素材阈值与当时软件限制也不作为新项目参数。现行执行规则仍由[剪点与检查](editing-and-qc.md)和[返修与交付核对](revision-checks.md)维护。

| 已遇到的机制 | 可迁移的检查方法 | 适用边界 |
|---|---|---|
| 声称无改动的脚本预演保持总时长，却改变了实际源端点 | 用原工程与回读后的实际源范围逐项比较；需要保持不变时可用检查器的 `--unchanged-from` | 有意重剪不要求源表保持相等；总长相等不能单独证明无改动 |
| 字幕文本操作与时间操作属于不同能力，跨片段合并不可直接完成 | 查当前工具实际接口与限制；验证一个代表条目的文字和时序后再扩展 | 不虚构创建字幕或设置时钟的命令，不把历史限制当当前能力结论 |
| 严格底噪检测没有候选，实际仍有呼吸、弱声与拖长气口 | 将时间轴洞、严格底噪、低能候选及字幕空档分开；回查当前剪后口播和动作 | 原片的分贝门槛、窗长与短淡化参数不能跨项目照搬 |
| 老报告列有某个图形，当前实际工程已没有 | 先回读当前工程并保存用户手改；按最新确认决定处理 | 旧资产数量与旧快照不是自动恢复依据 |
| 第三方模板未成功加载，却用近似风格重建了包装 | 区分模板已运行、仅复现风格、依赖仍缺失，并验证实际动态效果 | 同配色或同信息结构不能证明原模板成功运行 |
| 透明导出或目标格式被当前工具功能限制阻止 | 记录实际错误、交付影响与可行替代；先验证目标软件的代表片段 | 不绕过权限，也不把历史账号功能边界当所有用户的永久限制 |
| 工程能打开，但迁移后的字形、布局或运动并不等效 | 在目标软件检查文字、图层、透明、时序、声音和完整动态样本 | 工程可解析不等于视觉等效；不默默把要求可编辑的包装压平 |

软件接口名称随版本变化。调用前读取对应软件当前的 Skill、文档或工具定义；本页不提供隐藏接口、软件安装器或编辑器实现。OpenFilm 的项目加载、资源引用与真实音轨检查示例见[可选质量核对扩展](../integrations/openfilm-talking-head-qc/SKILL.md)。

# 返修与交付核对

在项目已有分镜、修订清单或验收记录中使用本页，不另维护一套固定格式。目标是让正确决定确实进入交付物，避免下一次生成、热更新或旧报告使返修失效。按本次范围取用，不强迫简单错字修改完成全片审计。

## 开工与交付检查

整片制作在已有项目记录中按“开工确认”逐项绑定本片版本、参考和用户例外。有意省略本应出现或用户点名的内容时记明理由。交付前按同一张表检查当前交付物，每项记检查结果或未验事项及影响。批量交付逐片核查。局部返修或仅导出时，核对本次变更、受影响的声画与下游，以及约定交付物，沿用既定内容和包装。

| 项目 | 开工确认 | 交付核对 |
|---|---|---|
| 版本与规格 | 确认当前基线、接续参考、交付节奏、工程或 MP4、目标平台、画幅与裁切约束，以及约定的分辨率和帧率。如需发布版和纯净版，分别记明字幕、音乐、音效、图层及原声的保留范围。 | 打开用户将收到的每个版本，核对画幅、时长和约定规格，播放首尾与代表段。纯净版按约定查应去的元素是否确实去除、应留口播是否完整。交付时提供成片文件或 [实际预览入口](#实际预览入口)，检查记录按需附上。 |
| 口播与动作 | 盘点全源及重录关系，明确必留信息与速度例外。同义重录质量相当时取最后一次完整表达，保留前遍独有信息，用户有明确选择时沿用。按 [停顿与动作一起处理](editing-and-qc.md#停顿与动作一起处理) 安排首轮剪辑和剪后的第二轮全片口播复查。 | 检查剪后重复表达、片内与词间气口、剪口两侧及低头读稿等无效动作。首轮剪后再做第二轮，仍有可处理的残留就继续。核对整句字头字尾、独有信息和动作衔接。 |
| 字幕与用词 | 明确原声口径、人工纠错、显示专用词及参考样式。同系列新片沿用已确认样式；选用本仓库样式时用 [竖屏口播字幕模板](packaging.md#竖屏口播字幕模板)。社媒口播采用默认无句末标点规则，用户另有约定时从其约定。 | 回读最后一次生成后的全部字幕，核对错字、句末标点、数字、断句和上屏时机。抽看单行、双行、最长句和切换处，确认底框包住各行，随文底框左右贴近最长行的实际字缘，文字在框内居中或按约定对齐。字幕位置按已确认样式核查。交付 MP4 时打开实际导出，抽播短单行、双行和最长句，按本片参考核对可见字高、字重、位置和底框。同时交工程时在工程入口分别核对。新增或改动的章节名、图解和字幕用词逐处对照口播与确认口径，包含只改显示词的例外。 |
| 画面与布局 | 记录构图、可否裁切及人物与图解的主次。给字幕、进度条和包装留位置。原片为 HDR 或此前出现色差时，确定本地原片对照和实际播放路径。 | 从交付入口核对肤色、构图及人物、书本等必留内容。有转色、代理或色差疑点时与 [本地原片](#颜色与播放路径对照) 同源同帧比较。检查图解与字幕抢位、平台界面遮挡，以及 [剪口与图层边界](editing-and-qc.md#视觉边界与闪帧检查)。实际平台显示无法验证时标明。 |
| 章节进度条 | 按 [章节进度条](packaging.md#章节进度条) 确定本片是否需要导航、有效章名、覆盖范围与平台显示位置。 | 看交付结果的片首、章节交界、全屏图解切换和片尾。确认进度跟随剪后的章界、章名对应当前内容，检查裁切与界面遮挡。 |
| 动态包装与配声 | 标出值得解释的段落、应有的运动、指定模板与音效作用。有指定参考片时按其声画表现设计。在基础时序稳定后制作并核验代表段落。 | 核对实际动效、选定模板的呈现及对应声音事件。播放代表动作、密集段和进出场，检查动画是否讲清关系、音效是否贴动作、在实际混音里能否听辨、口播是否清楚。对开头、章节入点与代表性图解分别核对适用的提示作用。核对用户指定的元素及同类段落，跟踪应采用却未进入成片的项目。 |
| 声画同步与结尾 | 检查开头、换源和已知噪声段的原声，明确需要处理的位置及保留的现场声。记录字幕、章节、图解和声音跟随的口播或画面锚点。 | 核对成片开头与已处理段的底噪、人声和背景声，检查处理边界的声底、音量与音画同步。剪点或速度变化后复查受影响的各轨与结尾。没有自然试听时，按实际完成的播放或客观分析说明核验范围。 |

## 当前决定进入实际生成来源

开始前核对用户正在看的工程与本次实际版本，保留可回退状态及本次不应改变的属性。已运行工程与上次生成结果不同，先比较差异并保留用户手改；不能只更新文件指纹使保护检查放行，再用旧快照重建。

将截图、文字和补充反馈逐项对应到原话或动作锚点；同一位置的多张截图可合并，连续短句中前后两处独立气口则分别核对，不能因属于同一句而漏掉其中一处。汇报压缩时区分本轮追加删除量、该处此前已删量与当前残留停顿；删了多少秒不能单独证明反馈已解决。

在实际字幕、选段表、声音配置或布局来源中保存已确认修订，随后回读生成的工程。源资产可以保留作回退，移除与否以实际播放引用为准。脚本、配置、可视编辑器都能写工程时，要明确本次真源及同步方向；生成脚本不应另有一份过期“最终结果”覆盖刚验收的数据。

用户拒绝某个音效时，先定位具体动作、文件及实例，区分“这一处”“全片同一素材”“这一类声音”。按已授权范围写入持久删除或替换决定；改变生成配置后核对拒绝项不再出现，也没有意外补入原先被筛掉的其他声音。单处删除不扩大成全类禁用，全片同款删除不能只删截图中的一处。最新明确决定覆盖此前保留决定，未拒绝的其他设置保持。

人工字幕修订关联可取得的源素材、原话与源位置，避免只存易失效的成片时间或临时条目 ID；重剪后更新实际字幕、使用中的代理/副本及逐字稿记录。只同步真正被调用的副本，不盲改所有备份。

## 按改动选择复验

| 实际改动 | 必要的复验对象 | 不能作为替代证据 |
|---|---|---|
| 基础剪辑转入包装制作 | 按 [整片制作的阶段](../SKILL.md#整片制作的阶段) 核对可回退基础版本、两轮气口的当前实际结果、源范围/速度/时长及字幕文字规则与显示，明确影响下游的开放项；包装计划关联原话和源锚点 | 基础版文件存在、只做首轮去重/静音扫描、待辨项自动判通过、只有规划或常驻导航便宣称包装已完成 |
| 整片制作完成、准备交付 | [视觉边界与闪帧检查](editing-and-qc.md#视觉边界与闪帧检查)：当前真实时基下各预期画面层的全部衔接边界、候选合成帧和相邻短段；保留有意黑场等例外 | 随机静帧正常、计划源表相接、底层或字幕有内容、只检查人物轨 |
| 只改字幕文字或句末标点 | 成片原话或用户已确认口径、最终原生cue全文与标点策略/语义例外、实际显示首末字、仍有效的分段/时序；生成来源同步且声画源范围未变 | 只改逐字稿/源ASR；忽略标点的文字守恒；称原声也已修好 |
| 整片口播初剪、删重复、压停顿、恢复字头 | [两轮气口处理](editing-and-qc.md#两轮气口处理与续做)：首轮落地后用当前实际口播做第二轮全片复查，继续处理长残留、短弱声、待辨与剪口叠加；复验完整句、同步画面、受影响下游与结尾 | 只做去重、只重跑旧候选表、完成两轮即通过、已剪过便不再看、ASR词起点/同文、字幕gap、总缩短量 |
| 同义重说、改口或重录去重 | 完整语义单元内的候选源范围、用户版本选择口径、保留的最后完整表达与前遍独有信息；实际舍弃范围、剪后整句及新字幕 | 只查相同字串或源重叠；原声/旧字幕字数守恒；保留前遍泛称后又接同义完整重说 |
| 复用字幕样式、改底框或固定位置 | [字幕显示验收](packaging.md#字幕标点与显示验收)：参考完整样式、实际单行/双行/最大行数的全部文字包框及字面在框内对齐、长短句和当前用户入口；保留文字与声画时序 | 同名字体/字号、底框存在、padding相等、只看单行、另一个窗口正确、保存成功 |
| 剪口或导入使字幕重新分段 | 实际原生条目的字序/次数、完整短语和数字、显示时刻；新增短条和拆分候选逐项处置 | 源VTT完整、拼接全文字数相等、检测报告已生成 |
| 改布局、字体、衬底或动画 | 用同一段口播对照原构图与候选样本：信息是否需要独立画面、人物/图解主次是否符合交流任务、重点和关系是否更易辨认；再核真实人物与内容边界、同类实例、入场/保持/退出及交接，并核对承诺保留的原声与字幕 | 场景配置有多种布局、人物轨道有片段、能渲染或元素没有越界 |
| 章节标签或导航 | 按 [章节进度条](packaging.md#章节进度条) 核对本片是否应有导航及其实际显示。核看首尾、章节边界与全屏图解切换处，章名对应剪后话题 | 包装计划已列、工程有轨道但未显示、进度公式正确、用“开场/交流”凑章 |
| 已明确目标平台的进度条或信息卡位置 | 该平台实际播放/预览入口截图中的裁切和界面覆盖；缺截图时记录为模拟或工程内检查，发布显示未验 | 编辑器内安全边距、估算坐标、历史平台坐标或另一平台的截图 |
| 插入或调整图片、题卡 | [呈现形式、阅读与时长](packaging.md#图片与题卡的呈现形式和时长)、位置/遮挡、实际首末可见帧与下段衔接；用户指定的结束点后连缩略形式也不再出现 | 只改完整图时长、角标仍延留；文件duration正确但当前预览仍显示 |
| 增删或替换音效/音乐 | 实际实例及文件、动作锚点、当段最终混音、密集重复与尾音、[同级逐项组的完整覆盖](packaging.md#同级罗列的声音一致性)；核对不应变的声音 | 素材文件存在、只查首项、孤立试听、附近静帧、峰值未削波 |
| 参考片整片包装或指定模板应用 | [实际素材采用](packaging.md#已有素材与模板的实际采用)、段落图形/动作/声音决定及最终实例；对照参考短段的运动与配声，复查长时间仅人物/字幕的区间是否符合设计 | 模板已下载、配色相同、导航常驻、卡片总数、仅章界提示音 |
| 颜色发白、调色或HDR/SDR转换 | [本地原片与实际播放路径](#颜色与播放路径对照)同源帧及相邻短段；代表源片的肤色、中间调、高光和暗部，派生媒体时钟及字幕关联 | 只看FFmpeg提帧、浏览器内部原片/代理相似、单张候选更浓或色标改为709 |
| 改了时长 | 字幕、章界、图形事件、音效和各轨尾点按各自源/语义锚点映射；给出当前时间码 | 一律平移/拉伸，继续沿用旧时间点 |
| 重生成、迁移或热载 | 生成输入与当前产物一致、已确认修订仍在、实际打开入口显示新结果；迁移另验目标软件样式 | 新文件的渲染正常，旧窗口自然会更新 |

检查器发现的候选要有处置：修改、核实后保留、或未能验证；结构通过不自动关闭候选。气口的“待辨、未命中优先表、无严格核心”等筛选状态按 [完成状态按证据结案](editing-and-qc.md#停顿与动作一起处理) 回查，不自动算核实保留。对于全片请求，不能让用户不断补报同类漏项才开始扫描。无须每轮重复已未受影响的整片检查，但要核对它确实未被改变。

给用户定位时使用“当前版本时间码 + 对应原话/视觉动作”，区分音效起点、动作时刻与静帧取样点。用户给近似时间先用于找目标；不能把“6:09 看过背景卡”写成“6:09 重音已听验”。

## 实际预览入口

交付工程或预览修改时，确认用户实际打开的项目、标签页和版本，再在该入口核对本次可见改动；这属于交付步骤，不只在热载异常时触发。保存/API回读证明写入，实际入口展示证明加载，分别核对。版本可用工具提供的标识、时长和具有区分度的修订内容确认；只改样式时总时长不变，必须看本次底框、位置等变化，不能只看项目名。

发现旧状态后，先检查并保存或保留未保存手改，再用工具支持的刷新/重开方式加载，回到相关句子或问题点核验。不要每次都强制刷新，也不要再开一个正确窗口便把用户原窗口当作已修复。实际入口不可访问时，交付可打开的位置和最小刷新/检查步骤，注明用户入口待验，继续已授权的独立检查，不伪称已显示。

## 预览异常的最小对照

先在用户报告位置及相邻短段复现；记录哪个版本、哪个入口、实时播放还是暂停跳转异常。以同源同时间比较原片、当前工程实际预览与已有原生渲染/输出，区分时间轴洞、媒体未就绪、裁切或遮挡、旧页面/图层状态，以及实际解码故障。只检查素材时长或轨道覆盖不能排除人物没绘出。

已确认保存后，可刷新/重开当前预览，回到原问题点检查人物、字幕、包装和短段播放。刷新恢复只证明恢复，不证明根因是缓存或 GPU；没有重复故障证据时不盲目重编码、重剪声音或修改全局软件。若实际成片有问题，不能用刷新正常掩盖。

代码生成的页面或组件被宿主按标识复用时，核对改动是否使实际实例更新，必要时用工具支持的重新加载或内容版本标识；这是有证据时的实现选择，不是所有软件的固定改法。若问题来自缓存生成，应验证源/缓存对照及修复后的重生成，不能只删缓存。

## 颜色与播放路径对照

画面发白、肤色或对比度异常时，先在用户正在看的入口复现，再用本机播放器打开真实原片，按源素材与源帧对齐，统一可比尺寸，比较相邻短段。去除诊断样本的额外调色后再判断基础显示；记录原片、实际使用的代理/派生媒体、色彩信息及应用中的滤镜。不同播放器或截图接口可能采用不同HDR映射，必要时用同一种系统截图方式复核；截图RGB差异只证明该捕获条件下的外观差异，不能单独给出解码根因。

浏览器直读原片与浏览器代理相似，只排除它们之间的部分差异，不证明与本地原片显示一致。按证据区分素材替换、错误色标、HDR/SDR映射、调色及旧预览；先修实际影响的项目链路，不以不断加重对比度/饱和度替代原因核查，不擅改系统HDR或所有项目设置。确需色彩转换时保留原片，派生素材保持源时钟、方向、帧率、原声与字幕对应，验证实际播放后再扩展。

候选要在当前交付入口与本地参考比较肤色、中间调、高光和暗部，覆盖本次涉及的代表源片及动态短段。技术格式通过、单帧更浓或转换成功不等于自然颜色已恢复；未解决的显示差异保持开放，不能被其他项检查通过覆盖。

## 证据随版本更新

在已有记录中保留本轮变更、当前工程/产物版本（版本号或文件指纹）、检查范围/方法、结果及未验证部分。音频重建还需标清来源工程、声道和处理。后续改动使旧证据不再覆盖的部分，要注明已被替代或需复验；未变部分可复用，不把旧整片测量说成新整片复测。

脚本回读时间、文字盒等字段时，先核实当前工具的字段名、单位、有限数值/非空值，并用已知样本对照实际显示；缺字段或非数值须报错。两个未取得的值相等、空列表无异常、规范化文字相等，都不能使相应时机、底框或标点验收通过。

交付结论分别说明已落地、客观检查、真实播放/听验和用户审美确认。素材标签、模型描述、波形与响度不能冒充亲自听过；抽样也不称全片。只剩用户听感验收时，给当前可打开入口和最少有代表性的定位点；若请求是最终 MP4，不能只交工程链接。未做的最终响度处理、导出或持续播放检查只在影响本次交付时明确说明。
